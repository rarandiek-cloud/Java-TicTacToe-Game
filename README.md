# Java Tic-Tac-Toe Game

## About the Project

This is a two-player Tic-Tac-Toe desktop game developed using Java Swing.

The game allows two players to compete on a 3×3 board, taking turns placing X and O until one player wins or the game ends in a draw.

This project was developed to practise Java programming and graphical user interface (GUI) development.

## Features

- Two-player gameplay (X and O)
- Interactive 3×3 game board
- Automatic player turn switching
- Winner detection
- Draw detection
- Score tracking
- Restart game functionality

## Technologies Used

- Java
- Java Swing
- IntelliJ IDEA

## Java Concepts Practised

- Object-Oriented Programming (OOP)
- Arrays
- For loops
- Conditional statements
- Methods
- Boolean variables
- Event handling
- GUI development

## How to Run the Application

1. Clone or download this repository.
2. Open the project in IntelliJ IDEA.
3. Open `TicTacToe.java`.
4. Run the `main()` method.
5. Start playing!
